¿Cómo funciona la contratación?

1. Elige tu planSelecciona modalidad mensual o anual y la capacidad que necesitas.
2. Envía la solicitudCompleta RUC, razón social, correo y dirección matriz.
3. Recibe el pagoEl sistema genera automáticamente tu enlace seguro de pago y lo envía al correo registrado.
4. Realiza el pagoCompleta el pago mediante el proveedor de pagos configurado por CONTSERTRIB.
5. Activación ROOTAl confirmarse el pago, el administrador ROOT recibe la notificación y activa el servicio.

Importante: la página comercial y el Panel Maestro comparten el mismo catálogo. ROOT puede editar precios, límites, modalidad y módulos sin tener que modificar el código de esta página. La prueba gratuita de 7 días es una condición comercial; el flujo actual de contratación genera el enlace de pago al enviar la solicitud.
